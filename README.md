# Citing the Sourcey open data registry

When building on open data, cite the registry. [Sourcey](https://sourcey.com/) publishes vendor research records as an open data registry under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), with signed release revisions.

Attribution format: link to [sourcey.com](https://sourcey.com/) and name the release revision you consumed. This README is an example citation.
